# homebrew-tap

Homebrew Formulae and Casks for VSHN's projects

## [espejote](https://github.com/vshn/espejote)

An in-cluster templating controller.

```
brew install vshn/tap/espejote
```

## [kharon](https://github.com/vshn/kharon)

Smart cluster access solution tailored to VSHN. Kharon ferries your connections safely across SSH jumphosts into private networks.

```
brew install vshn/tap/kharon
```
